## [LEARN:gotchas] Build pitfalls | Date: 2026-09-23 | What: (1) In EJS templates, never indent HTML by 4+ spaces: Quarto passes template output through Markdown and indented lines become code blocks. (2) Two `[..]{.class}` spans on consecutive lines merge into one paragraph and break the two-column rows; keep a blank line between them. A fenced div also needs a blank line before it. (3) A local `python -m http.server` started inside `docs/` locks the folder and makes `quarto render` fail ("used by another process"); serve from the project root instead. (4) Headless Chrome lays pages out at a minimum 500px width, so a 390px screenshot looks clipped when the site is fine. | Open: —
